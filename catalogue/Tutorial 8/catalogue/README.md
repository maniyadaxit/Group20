# CampusEats Catalogue — CS543 Tutorial 8

A small catalogue application built with **Node.js**, **Express**, HTML, CSS, and browser JavaScript. It demonstrates the browser → REST API → data flow from the Node & Express tutorial.

The menu is stored in an in-memory JavaScript array. Data resets when the server restarts; a database is outside the scope of this tutorial.

## Requirements

- Node.js 18 or newer
- npm (installed with Node.js)

Check your installation:

```bash
node -v
npm -v
```

## Run the project

Open a terminal in this `catalogue` folder and run:

```bash
npm install
npm start
```

Open **http://localhost:3000** in your browser. Do not open `public/index.html` directly as a file: the page must be served by Express so that its relative API requests reach the server.

To stop the server, press `Ctrl + C`.

## REST API

| Method | Endpoint | Purpose | Success response |
| --- | --- | --- | --- |
| GET | `/items` | List all dishes | `200 OK` with a JSON array |
| GET | `/items/:id` | Retrieve one dish | `200 OK` with a JSON object |
| POST | `/items` | Add a dish | `201 Created` with the new dish |

### Initial menu

```json
[
  { "id": 1, "name": "Veg Thali", "price": 90 },
  { "id": 2, "name": "Paneer Roll", "price": 70 }
]
```

### Test the read endpoints

```bash
curl -i http://localhost:3000/items
curl -i http://localhost:3000/items/1
curl -i http://localhost:3000/items/99
```

The last request returns `404 Not Found` with:

```json
{ "error": "not found" }
```

### Test the create endpoint

```bash
curl -i -X POST http://localhost:3000/items \
  -H "Content-Type: application/json" \
  -d '{"name":"Masala Dosa","price":60}'
```

The response uses `201 Created` and contains the newly created dish, for example:

```json
{ "id": 3, "name": "Masala Dosa", "price": 60 }
```

A missing or blank name returns `422 Unprocessable Entity`:

```bash
curl -i -X POST http://localhost:3000/items \
  -H "Content-Type: application/json" \
  -d '{"price":60}'
```

A negative or non-numeric price also returns `422`. If the price is omitted, it defaults to zero.

## How the application works

1. Express serves the files in `public/` using `express.static()`.
2. The page calls `GET /items` when it loads and creates a menu card for each returned dish.
3. The add-dish form sends a JSON body to `POST /items` using `fetch()`.
4. The server validates the name and price, adds a new ID, stores the dish in the array, and responds with `201`.
5. The browser reloads the menu after a successful POST.

The browser uses DOM text nodes for dish names, rather than inserting user input as HTML.

## HTTP status codes

- `200` — successful GET request.
- `201` — a dish was created.
- `400` — malformed JSON request body.
- `404` — the requested dish ID does not exist.
- `422` — the submitted dish name or price is invalid.

## Notes

- The server uses `process.env.PORT` when provided; otherwise it listens on port `3000`.
- `node_modules/` is generated by `npm install` and should not be committed.
- The application intentionally uses in-memory data, as specified in the tutorial.
